# Корпоративний сайт «НОВА ДОРОГА» (Neue Wege GmbH)

**Офіційний корпоративний сайт австрійсько-української аграрної компанії Neue Wege GmbH / ТОВ «НОВА ДОРОГА».**

Сайт реалізовано на сучасному стеку **Next.js (App Router)** з повною статичною генерацією (SSG), підтримкою 3 мов (`de` — основна за замовчуванням, `uk`, `en`), централізованим керуванням даними без CMS та строгою типізацією **TypeScript** і **Tailwind CSS v4**.

---

## 1. Технологічний стек

- **Фреймворк:** Next.js (App Router, Server Components)
- **Мова:** TypeScript (Strict mode)
- **Стилізація:** Tailwind CSS v4 (фірмові токени пурпуровий `#4B176B`, золото `#C8A04A`, глибокий пурпуровий `#321044`)
- **Іконки:** Lucide React
- **Локалізація:** Типізовані словники (`de`, `uk`, `en`) без зайвих важких залежностей
- **Хостинг та деплой:** Vercel / Будь-який статичний хостинг
- **SEO:** `sitemap.xml`, `robots.txt`, hreflang та OpenGraph метадані

---

## 2. Структура сайту (7 основних розділів)

1. **Головна** (`/[locale]/`) — презентаційний Hero, огляд 5 напрямків діяльності, промо-блок міжнародної виставки в Генті (14–17 січня 2027), пакети співпраці та останні публікації.
2. **Про нас** (`/[locale]/about`) — місія та мета компанії, детальний опис 5 аграрних секторів, австрійське керівництво та представництво в Україні.
3. **Наші послуги** (`/[locale]/services`) — повний прайс-лист окремих послуг (відео 470 €, друк 350 €, банер 450 € тощо), пакети «Економ» (від 1 000 €, дод. послуги +30%) та «Платиновий» (2 040 € сума окремо, пакет узгоджується), порівняльна таблиця та податкові умови.
4. **Виставки та заходи** (`/[locale]/events`) — презентація участі в аграрній виставці в Генті, Бельгія (Flanders Expo, 70 000 відвідувачів, 50 000 м²), концепція представництва без особистого виїзду та 5 форматів присутності.
5. **Партнери** (`/[locale]/partners`) — інформація про австрійську благодійну організацію «Надія та Гідність» (Hoffnung & Würde, Wien, ZVR 1984068166), європейські торговельні мережі та селекційні центри.
6. **Статті** (`/[locale]/articles`) — база знань, вимоги ЄС до експорту зернових, стандарти якості та підготовка до виставок.
7. **Реквізити та адреса** (`/[locale]/contact`) — офіційні юридичні реквізити (Impressum), адреса у Відні (Wien, Österreich), підтверджені номери телефонів та онлайн-форма зворотного зв'язку.

## 3. Локальний запуск проекту

### Вимоги
- Node.js версії 18.18+ або 20+
- npm (або pnpm/yarn)

### Команди:
```bash
# Перехід у папку проекту
cd /Users/maxbmaapc/.gemini/antigravity-ide/scratch/neue-wege-website

# Встановлення залежностей (якщо потрібно)
npm install

# Запуск локального dev-сервера
npm run dev
```

Відкрийте в браузері: `http://localhost:3000` (автоматично перенаправляє на німецьку версію `/de`). Для української версії: `http://localhost:3000/uk`.

### Перевірка збірки (Production Build):
```bash
npm run build
```
Усі 44 сторінки генеруються автоматично у статичний вигляд за кілька секунд без помилок.

## 4. Як редагувати контент (без CMS)

Весь контент централізовано винесено у папку `src/data/`:
- `src/data/contacts.ts` — номери телефонів, адреса, посилання на месенджери, юридичні назви.
- `src/data/services.ts` — ціни послуг, технічні параметри (хвилини, тиражі, періодичність).
- `src/data/packages.ts` — ціни та склад пакетів Економ / Платиновий.
- `src/data/activities.ts` — 5 аграрних напрямків діяльності компанії.
- `src/data/exhibition.ts` — дати виставки в Генті, адреса, статистика відвідувачів.
- `src/data/partners.ts` — список партнерських організацій та опис.
- `src/data/articles.ts` — статті, дати та тексти публікацій.

Тексти інтерфейсу трьома мовами знаходяться у:
- `src/i18n/dictionaries/de.ts` (Німецька — основна)
- `src/i18n/dictionaries/uk.ts` (Українська)
- `src/i18n/dictionaries/en.ts` (Англійська)

## 5. Публікація на Vercel

1. Завантажте папку проекту у ваш Git-репозиторій на GitHub.
2. У панелі [Vercel](https://vercel.com) виберіть «Add New Project» -> імпортуйте репозиторій.
3. Vercel автоматично розпізнає **Next.js** проект.
4. Натисніть **Deploy**.
5. За потреби підключіть власний домен (наприклад `neuewege-gmbh.at` або `novadoroga.ua`) у налаштуваннях доменів Vercel.
